## Cover

# Two portfolios. One authored point of view.

**Ettilapse Photography — Chromatic Monograph**  
**Technical Portfolio — Signal Lab**

## Slide 1

# One identity, two operating systems

| Shared spine | Photography mode | Technical mode |
| --- | --- | --- |
| Authored type, intentional motion, real process, confident simplicity | Emotional, image-first, editorial | Evidentiary, system-first, operational |
| One personal point of view | "I see moments differently." | "I make useful things work." |
| Clear action paths | Explore stories → inquire | Inspect builds → read notes → connect |

**Design decision:** do not force clients and technical reviewers through the same visual experience.

## Slide 2

# The 2026 edge is authored structure

- Use **visible logic**, not generic glass cards or AI-gradient wallpaper.
- Pair **high-tech clarity** with a warm, tactile human touch.
- Make typography, color, and motion reveal a specific point of view.
- Let every "wow" moment explain, orient, or confirm something.

> The goal is memorable work—not a memorable template.

## Slide 3

# Photography becomes a living monograph

**Chromatic Monograph** combines a museum-like calm with a color-led way to explore.

| Design layer | Expression |
| --- | --- |
| Canvas | Warm paper, deep ink, restrained grain |
| Type | Large editorial serif + crisp interface grotesk |
| Accent | Vermilion and ultramarine used as navigation signals |
| Composition | Deliberate asymmetry; photographs always get room to breathe |

**Feeling:** cinematic, personal, premium, and easy to trust.

## Slide 4

# The gallery turns browsing into discovery

**Functional flow**

`Chromatic Index` → `Project preview` → `Immersive Story Reader` → `Inquire`

| Interaction | What the visitor gains |
| --- | --- |
| Color/mood-led index | A memorable way to find the right work fast |
| Index / Story mode | Control between scanning and immersion |
| In-place image expansion | Context is retained; the visitor never feels lost in a generic modal |
| Story-end inquiry prompt | A natural next step while emotional impact is highest |

**Design rule:** the gallery is a guided exhibition, not an image dump.

## Slide 5

# Mobile makes the story immediate

| Desktop | Mobile |
| --- | --- |
| Asymmetric index, hover previews, wide editorial pacing | Large tap targets, one-thumb story reader, simple visual index |
| Keyboard-enabled reader and context rail | Clear close/back, visible image count, optional next/previous controls |
| Subtle spatial transitions | Static-first fallback with no gesture dependency |

**Principle:** mobile is an intentional editorial composition—not a shrunken desktop grid.

## Slide 6

# Technical work becomes proof, not decoration

**Signal Lab** gives hardware, AI tools, scripts, and business websites one credible visual home.

| Design layer | Expression |
| --- | --- |
| Canvas | Carbon black, signal fog, instrument-grade contrast |
| Type | Strong grotesk headings + mono labels for data and system detail |
| Accent | Mint = live / connected; chartreuse = selected / outcome; red = constraint |
| Composition | Responsive technical grid with actual artifacts, not sci-fi decoration |

**Feeling:** capable, precise, curious, and real.

## Slide 7

# Every project exposes its real system

**Project-card behavior**

`Artifact` → `Outcome` → `Constraint` → `System View` → `Proof` → `Build Notes`

| Work type | Proof artifact |
| --- | --- |
| ESP32 / embedded | Board photo, wiring/system map, telemetry, runtime or test observation |
| AI application | Real input → workflow → reviewed output; fallback or validation state |
| Script / automation | Task flow, usable output, implementation rationale |
| Business website | User task, interface state, before → after workflow, validated result if available |

**Credibility rule:** do not hide limitations; frame them as engineering decisions.

## Slide 8

# Lab Notes compound credibility

The technical blog is not a detached "posts" page. It is a connected evidence layer.

- Notes attach to builds through simple relationships: `uses`, `extends`, `measured by`, `wrote about`.
- Short posts show iteration: test, result, decision, next step.
- Long-form articles make complex work legible to clients and collaborators.
- The visible archive proves sustained thinking beyond a finished screenshot.

**Result:** projects become a working body of knowledge, not isolated tiles.

## Slide 9

# Motion helps visitors understand

| Moment | Purpose | Reduced-motion behavior |
| --- | --- | --- |
| Gallery tile → story image | Preserve spatial context | Instant open with clear back path |
| Project card focus | Reveal stack, state, or constraint | Color and border change only |
| System diagram | Explain input → transform → output | Static diagram with text explanation |
| Case-study reading progress | Orient long-form reading | Static marker |

**Non-negotiable:** no scroll hijacking, fake terminals, cursor trails, or effects that delay access to content.

## Slide 10

# Build the signature moments first

| Phase | Ettilapse Photography | Signal Lab |
| --- | --- | --- |
| 1. Foundation | Curated stories, inquiry path, image delivery | Project index, three deep case studies, Lab Notes template |
| 2. Signature interaction | Chromatic Index + story reader | Artifact cards + actual system diagram |
| 3. Proof and cadence | Approved social proof and new collections | Demos, decisions, project relationships, regular notes |
| 4. Polish | Accessibility, responsiveness, conversion testing | Reduced motion, keyboard flow, performance testing |

**Start small:** one exceptional gallery mechanic and one exceptional project case study beat a dozen half-finished visual effects.
